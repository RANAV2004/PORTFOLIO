01 — Who I am

About & Skills

About

I'm a software engineer with a B.Tech in Computer Science and Engineering (AI specialisation, 2026). I build full-stack applications in Python, FastAPI and React. I'm at my best when a system fails in ways that aren't obvious: I trace the bad result back to the data or the algorithm causing it and fix it there.

That's how I built SkyRail, a live train-route planner running on Indian Railways data. Before routing could work, I rebuilt 331 broken timetables and placed 269 stations that had no coordinates, which gave me a clean network of 4,735 stations. Yen's algorithm kept returning near-identical routes, so I replaced it with a penalty-based Dijkstra that finds genuinely different ones. I trained a LightGBM delay model on 1.17M real arrival records, checked it against a historical-average baseline, and shipped the whole system with 49 automated tests.

I've done the same kind of work for others. As a Data Analyst Intern at Sustainable Ships (Norway, remote), I wrote Python automation that cut manual lookup time by about 40% and merged inconsistent vessel data from five classification societies into one schema. In 1.5+ years of freelancing I've delivered client projects from requirements through deployment. I've also published research on cryptocurrency price prediction using ML and deep learning.

I'm looking for a full-time Software Engineer or AI/ML Engineer role on a team that wants software that works on real data.
